# ADR-029 — 学習パスの分岐を廃止し全員共通の一本道にする

## Status

Accepted（2026-08-09）

## Context

[`curriculum.md`](../../curriculum.md) は学習パスを若手向けと中堅向けの 2 本に分けていた。若手は STEP-01 から 03 を順に実施して Beginner の課題へ、中堅は STEP-03 を任意確認でスキップして Intermediate 以上の課題へ進む構成である。[`overview.md`](../../overview.md) のペルソナ表とステークホルダー表、[`review-criteria.md`](../../develop/review-criteria.md) のレビュー観点表も同じ 2 分類を軸にしていた。

**2 回目の実施に向けて作成した必須タスク表は、この分岐と食い違う。** 運営者が用意した表は、オリエンテーション、環境構築、ドキュメント読み込み、初級課題（AI-DLC なし）、初級課題（AI-DLC あり）、中級課題（AI-DLC あり）の 6 項目をすべて必須としている。分岐前提のドキュメントをそのまま残すと、学習者はサイトの記述と配布された表のどちらに従えばよいか判断できない。

**分岐は運用実績を持たない設計である。** 1 回目の実施者は 1 名で、分岐が機能したかを確かめる機会がなかった。分岐は将来的な受講者層の広がりを見越して先回りで用意したものであり、現時点で維持する根拠は「後で必要になるかもしれない」に留まる。一方で分岐はドキュメント全体に波及しており、記述の整合を保つコストは実際に発生している。

## Decision

**学習パスの分岐を一旦廃止し、全学習者が同じ順序で同じ課題に取り組む一本道にする。**

- **若手・中堅の区分を学習者から外す。** ペルソナは「学習者」1 つとし、到達目標は従来の中堅の水準（AI ツールを使い分けながら独立した機能追加・設計ができる）を採る。全員が中級課題まで到達するためである。
- **必須課題は必須タスク表のとおりとする。** オリエンテーション（1 時間）、STEP-01 環境構築（1〜2 時間）、STEP-02 ドキュメント読み込み（4 時間）、STEP-03 初級課題（AI-DLC なし、3〜4 時間）、初級課題（AI-DLC あり、2〜3 時間）、中級課題（AI-DLC あり、4〜7 時間）の計 15〜21 時間。[ADR-023](./ADR-023-mentor-gate-removal.md) で再計算した推定工数とは STEP-01 と STEP-03 で差があるが、今回の実施に用いる表の値を採る。
- **「選択課題」の語は残し、意味を狭める。** 選べるのはどの課題をやるかであって、やるかどうかではない。難易度は段階ごとに決まる。Issue テンプレート名（`選択課題（エンハンス）`）や各スキルの説明にこの語が定着しているため、語の入れ替えはしない。
- **Advanced はカタログに残し、必須パスの外の任意課題とする。** 必須タスク表に含まれないが、中級課題まで終えた学習者の行き先として要件シートごと残す。
- **[`review-criteria.md`](../../develop/review-criteria.md) のレビュー観点表は、軸を学習者の分類から課題の段階に置き換える。** 従来の若手・中堅の 2 列を初級課題時・中級課題時に読み替え、重点の配分は変えない。パスが一本になったことで、重点は人によってではなく進行に応じて移るためである。
- **[ADR-028](./ADR-028-training-purpose.md) は改訂しない。** 同 ADR がペルソナ表を引用している箇所は決定時点の記述を指しており、記録として残す。

## Consequences

- 中堅相当の経験を持つ学習者も STEP-03（AI-DLC なしの初級課題）を実施する。習熟済みの学習者には冗長になりうるが、[STEP-03 の設計意図](../../curriculum.md#step-03)である「AI-DLC の有無を対比で体感する」は AI 駆動開発の経験がない学習者には成立するため、受け入れる。
- 分岐が必要になった時点で本 ADR を改訂する。「一旦廃止」であり、分岐の設計そのものを否定したわけではない。判断材料は 2 回目の実施で得られる所要時間と難易度の実測になる。
- 旧ドキュメントサイト（`Docs/` 配下、Zensical）には分岐前提の記述が残る。GitHub Pages に公開されているのは `docs-next` のみ（`.github/workflows/docs.yml`）であるため、公開面では矛盾しない。ただし `CLAUDE.md` と `.claude/rules/` が `Docs/guide/` を参照している間は、Claude Code が旧記述を読む。参照先の付け替えは別タスクで行う。
- 必須タスク表の工数を採ったことで、[ADR-023](./ADR-023-mentor-gate-removal.md) で再計算した値と差が残る。実測との突き合わせは 2 回目の実施後に行う。
