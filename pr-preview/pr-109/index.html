BookFlow ドキュメントAI 駆動開発チュートリアル

施設・備品予約サービス BookFlow に機能を足しながら、
Claude Code による AI 駆動開発を身につける社内チュートリアルです。

なぜこのリポジトリを作ったか（Why）

ソフトウェア開発では、AI エージェント（指示を受けてコードを読み書きするツール。このリポジトリでは Claude Code を使います）を前提とした進め方が広がっています。 それに伴い、AI エージェントを使って開発できる人材が求められる場面が増えています。

とはいえ、AI エージェントを触ったことがなければ、何から始めればいいのか分かりません。 必要なのはチャットで質問できることではなく、仕様を決め、コードを書かせ、出てきたものを確かめ、レビューを通してマージするところまでを AI と一緒に進めることです。 この一連の進め方を AI 駆動開発 と呼びます。

ここでやるのは、その一通りを実際に動いているサービスで経験することです。 予約サービスに機能を 1 つ足す作業を通して、Claude Code の使い方から、仕様を先に決める進め方、AI レビューとの付き合い方までを身につけます。

学習を終えたときにできること（What）

AI 駆動開発を自分ひとりで回せるようになります。

  • 画面からデータベースまでまたがる機能を、計画から実装、レビュー、マージまで自分ひとりで仕上げられる
  • AI エージェントに渡す情報を組み立て、意図した成果が出るように指示を出せる
  • AI が出した計画や仕様、コードの誤りに気づき、自分で直せる
  • どこまで AI エージェントに任せ、どこから自分で判断するのかを線引きできる
  • 最初の 1 課題は AI-DLC を使わずに進めるため、エンジンが何を代行しているのかを対比で説明できる
  • BookFlow で身につけた進め方を、別のコードベースでも再現できる

始め方（How）

はじめて触る
  1. 環境構築
  2. 開発フローの理解
  3. AI ツール活用
必須ステップを終えた
  1. カタログから未実施の課題を選ぶ
  2. 標準開発フローを見直す
用語や仕様を調べたい
  1. 用語集
  2. 仕様書インデックス

運営者は 運用ガイド へ。 Claude Code に読ませる 設定台帳 も用意しています。

必須課題の全体像

学習パスは 1 本です。経験年数やレベルによる分岐はなく、全員が同じ順序で進めます。
STEP-01 から中級課題まで、目安は合計 17〜24 時間です。

🛠
STEP-01

キックオフと環境構築

DevContainer を起動し、ブラウザで BookFlow のダッシュボードにアクセスできる状態を作る。

  • オリエンテーションに参加
  • バックエンドの health が UP
  • サインイン画面の表示
この STEP を進める →
🔄
STEP-02

リポジトリ運用・開発フローの理解

ブランチの切り方と標準開発フロー、AI レビューの位置づけを理解し、実装を始められる状態を作る。

  • 標準開発フローを説明できる
  • AI レビューの完了条件を理解する
  • ブランチを 1 本作成する
この STEP を進める →
🤖
STEP-03

初級課題1回目（AI-DLC を使わない）

Claude Code の特性を理解する。最初の Beginner 課題をあえて /aidlc を使わずに進め、使った場合との差を体感する。

  • Claude Code のセットアップ
  • /aidlc なしで 1 課題を完了
  • 感じた手間を PR に記載
この STEP を進める →
🚀
必須・2〜3 時間

STEP-03 と同じ課題を、今度は標準開発フロー（AI-DLC）に沿って実装し直し、エンジンが何を代行しているかを対比で捉える。
