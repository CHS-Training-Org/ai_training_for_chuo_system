# User Stories — カレンダービュー（Issue #27）

対象ペルソナ：[利用者（BookFlow ユーザー、全ロール共通）](./personas.md)

## US-01: カレンダー形式での空き状況表示

**As a** 利用者、**I want** リソース詳細画面でカレンダー形式の空き状況を見られること、**so that** 週・月単位の混雑感を一目で把握できる。

**対応要件**: RSV-01, RSV-05

**受入条件**:
- `/resources/{id}` を開くと、カレンダー形式の空き状況ビューが表示される
- 既存の空き確認リスト（当日〜7日後の占有時間帯一覧）はカレンダーと併存し、削除されない

## US-02: 週表示・月表示の切り替え

**As a** 利用者、**I want** カレンダーの表示単位を週・月で切り替えられること、**so that** 直近の詳細な空き状況と中長期の混雑感の両方を確認できる。

**対応要件**: RSV-02

**受入条件**:
- カレンダー上に週表示・月表示を切り替える操作がある
- 切り替え後、選択した表示単位でカレンダーが再描画される

## US-03: 週表示での空き枠クリックによる予約フォームへの遷移

**As a** 利用者、**I want** 週表示のカレンダー上で空いている時間枠をクリックすると予約申請フォームに遷移すること、**so that** 空き時間を見つけてからの予約操作を一手で行える。

**対応要件**: RSV-03

**受入条件**:
- 週表示で予約済みの時間枠はグレーアウトされ、クリックできない
- 週表示で空いている時間枠をクリックすると `/reservations/new` に遷移し、クリックした時間枠の開始日時が引き渡される

## US-04: 月表示での日セルクリック時の週表示への切り替え

**As a** 利用者、**I want** 月表示で気になる日をクリックするとその日を含む週の週表示に切り替わること、**so that** 月表示で見つけた候補日から時間枠単位の選択にスムーズに進める。

**対応要件**: RSV-06（明確化質問の回答により確定）

**受入条件**:
- 月表示で日セルをクリックすると、その日を含む週の週表示に切り替わる
- 月表示では時間枠単位のクリックによる予約フォーム遷移は行わない（遷移は週表示でのみ発生する）

## US-05: 表示期間の移動と空き情報の再取得

**As a** 利用者、**I want** カレンダーの表示期間を前後に移動できること、**so that** 将来の空き状況を確認して都合の良い日時を探せる。

**対応要件**: RSV-04

**受入条件**:
- 週表示では前週・次週に、月表示では前月・次月に移動する操作がある
- 表示期間を移動すると、その期間に対応する `GET /api/resources/{id}/availability` の呼び出しが行われ、カレンダー表示が更新される
