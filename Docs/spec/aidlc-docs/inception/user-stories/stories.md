# User Stories — calendar-view

## US-01: カレンダー形式での空き状況閲覧

**BookFlow 認証済みユーザーとして**、リソース詳細画面でカレンダー形式の空き状況を見たい。**それによって** リスト形式より直感的に週・月単位の混雑感を把握できる。

### 受入条件

```gherkin
Scenario: リソース詳細画面にカレンダーが表示される
  Given BookFlow 認証済みユーザーがリソース詳細画面（/resources/{id}）を開いている
  When 画面が表示される
  Then カレンダー形式の空き状況ビューが表示される
  And 既存の「空き状況（予約済み一覧）」リスト表示は表示されない（RSV-05 決定事項：カレンダーへの置き換え）

Scenario: 週表示と月表示を切り替えられる
  Given リソース詳細画面のカレンダーが表示されている
  When 表示切り替えコントロールで「月表示」を選択する
  Then カレンダーが月表示に切り替わる
  When 表示切り替えコントロールで「週表示」を選択する
  Then カレンダーが週表示に切り替わる
```

## US-02: 表示期間の移動

**BookFlow 認証済みユーザーとして**、カレンダーの表示期間を前後に移動したい。**それによって** 今週・今月以外の空き状況も確認できる。

### 受入条件

```gherkin
Scenario: 週表示で前週/次週に移動する
  Given カレンダーが週表示になっている
  When 「次週」を選択する
  Then 表示期間が1週間先に進み、その期間の空き情報が再取得されて表示される
  When 「前週」を選択する
  Then 表示期間が1週間前に戻り、その期間の空き情報が再取得されて表示される

Scenario: 月表示で前月/次月に移動する
  Given カレンダーが月表示になっている
  When 「次月」を選択する
  Then 表示期間が1か月先に進み、その期間の空き情報が再取得されて表示される
  When 「前月」を選択する
  Then 表示期間が1か月前に戻り、その期間の空き情報が再取得されて表示される
```

## US-03: 空き枠クリックによる予約申請フォームへの日時引き継ぎ

**BookFlow 認証済みユーザーとして**、カレンダー上の空き枠をクリックして予約申請フォームに開始日時を引き継ぎたい。**それによって** 日時を手で入力し直す手間を省ける。

### 受入条件

```gherkin
Scenario: 週表示で時間帯マス目をクリックする
  Given カレンダーが週表示になっている（1時間単位のグリッド、8:00〜20:00）
  And ある曜日・時間帯のマス目が空き枠として表示されている
  When そのマス目をクリックする
  Then 予約申請フォーム（/reservations/new）に遷移する
  And 開始日時入力欄に、クリックした曜日・時刻が初期値として反映されている

Scenario: 月表示で日セルをクリックする
  Given カレンダーが月表示になっている
  And ある日のセルが空きを含む状態で表示されている
  When その日のセルをクリックする
  Then 予約申請フォーム（/reservations/new）に遷移する
  And 開始日時入力欄に、クリックした日の既定時刻（9:00）が初期値として反映されている
  And 利用者は予約申請フォーム上で時刻を調整できる
```

## US-04: 予約済み枠の視覚的区別

**BookFlow 認証済みユーザーとして**、カレンダー上で予約済みの枠と空いている枠を見分けたい。**それによって** 誤って埋まっている時間帯を選ぼうとせずに済む。

### 受入条件

```gherkin
Scenario: 予約済み枠がグレーアウトされる
  Given カレンダーに表示期間中の予約済み枠（PENDING または APPROVED の予約）が含まれている
  When カレンダーが表示される
  Then 予約済みの枠はグレーアウトされ、クリックできない
  And 空いている枠は通常の表示でクリックできる
```
