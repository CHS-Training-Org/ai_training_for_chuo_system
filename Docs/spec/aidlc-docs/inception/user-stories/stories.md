# User Stories: CSV 帳票出力

## US-01: 予約実績を CSV でダウンロードする

**管理者として**、予約一覧を CSV ファイルでダウンロードしたい。**それは** Excel での集計や社内報告に使いたいからだ。

### 受け入れ基準

- **Given** 管理者として `/admin/reports` にアクセスしている
- **When** 「CSV ダウンロード」ボタンをクリックする
- **Then** 予約一覧（予約 ID・リソース名・申請者名・開始日時・終了日時・目的・承認状態）を含む CSV ファイルがブラウザにダウンロードされる
- **And** CSV は日本語ヘッダ行を持ち、UTF-8 BOM 付きで Excel で開いても文字化けしない
- **And** 期間・ステータスを指定しなければ全ユーザーの全期間・全ステータスの予約が対象になる

### INVEST チェック
Independent（絞り込み条件なしの基本機能）／Negotiable（列や書式は実装時に微調整可）／Valuable（社内報告の手作業を削減）／Estimable／Small（単一エンドポイント + 単一ボタン）／Testable（受け入れ基準が具体的）

---

## US-02: 期間・ステータスを絞り込んで CSV をダウンロードする

**管理者として**、出力対象の期間と承認ステータスを指定して CSV をダウンロードしたい。**それは** 必要なデータだけに絞って報告資料を作りたいからだ。

### 受け入れ基準

- **Given** 管理者として `/admin/reports` を開いている
- **When** 開始日・終了日・承認ステータスを指定して「CSV ダウンロード」をクリックする
- **Then** 指定した期間内に開始日時があり、指定したステータスに該当する予約のみが CSV に含まれる
- **And** 開始日のみ・終了日のみといった片方だけの指定もできる
- **And** 開始日が終了日より後という不正な組み合わせを指定した場合はエラーが表示され、ダウンロードは行われない

### INVEST チェック
Independent（US-01 の拡張だが単体でも検証可能）／Negotiable／Valuable（報告対象の絞り込みという明確な価値）／Estimable／Small／Testable（境界値・不正値のケースが明確）

---

## US-03: 管理者以外はアクセスできない

**MEMBER または APPROVER として**、帳票出力ページや CSV エンドポイントにアクセスしても操作できないようにしてほしい。**それは** 予約データは全ユーザー分を含むため、管理者以外に見せるべきではないからだ。

### 受け入れ基準

- **Given** MEMBER または APPROVER としてサインインしている
- **When** サイドナビゲーションを確認する
- **Then** 「帳票出力」メニューは表示されない
- **When** `/admin/reports` に直接 URL でアクセスする
- **Then** 403 エラー画面が表示される
- **When** `GET /api/reports/reservations/csv` を直接呼び出す
- **Then** 403 Forbidden（`code: FORBIDDEN`）が返る
- **And** 未認証でアクセスした場合は 401 Unauthorized が返る

### INVEST チェック
Independent（認可の検証は他ストーリーと独立してテスト可能）／Negotiable／Valuable（データ漏洩防止という明確な価値）／Estimable／Small／Testable（ロールごとの期待値が明確）
