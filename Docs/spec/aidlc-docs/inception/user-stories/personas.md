# Personas — カレンダービュー（Issue #27）

## 利用者（BookFlow ユーザー、全ロール共通）

- **ロール**：MEMBER / APPROVER / ADMIN のいずれでも共通（`/resources/{id}` は全ロールが閲覧でき、画面上の挙動に差異がないため分割しない）
- **特徴**：会議室・備品などのリソースを予約したい、または予約前にリソースの空き状況を確認したい BookFlow ユーザー
- **動機**：希望する日時にリソースが空いているかを素早く把握し、空いていればそのまま予約申請に進みたい
- **現状の課題**：既存の空き確認リスト（当日〜7日後の占有時間帯の一覧）では、週・月単位の混雑感が把握しにくく、空いている日時を探すのに一覧を読み解く手間がかかる
