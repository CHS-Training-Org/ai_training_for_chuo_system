# Personas — カレンダービュー（Issue #27）

## 粒度の判断

本機能（リソース詳細画面のカレンダービュー）は、閲覧・週月切替・期間移動・空き枠クリックのいずれの操作も、ロール（`MEMBER`・`APPROVER`・`ADMIN`）によって挙動が変わらない。既存の`requirements.md`でも「ロールごとの権限差異なし」と整理済みであるため、単一ペルソナで定義する（ユーザー確認済み、2026-08-14T09:20:00Z）。

## リソース利用者

- **役割**: 施設・備品を予約する社内利用者。Cognitoロールは `MEMBER`・`APPROVER`・`ADMIN` のいずれか（本機能上は区別しない）。
- **ゴール**: 目的の日時にリソース（会議室・備品等）が空いているかを素早く把握し、空いていればその場で予約申請に進みたい。
- **現状の課題**: 既存の空き確認はテキストリスト（当日〜7日後の予約済み時間帯の羅列）のみで、週・月単位の混雑感（曜日ごとの傾向、月内の繁忙期）を一目で把握できない。
- **利用場面**: 会議室を予約する前に、来週・来月の空き状況を確認してから日程を調整する。定例会議のように毎週同じ曜日・時間帯で予約したい場合、その曜日の埋まり具合を横断的に見たい。
- **技術的な前提**: 既存のリソース詳細画面（`/resources/{id}`）に到達済みであり、認証済みである（`(authenticated)`ルートグループ配下）。
