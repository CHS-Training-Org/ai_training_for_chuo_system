# Personas — 予約一覧のフィルタ拡張

## ペルソナ 1: BookFlow 認証済みユーザー（主ペルソナ）

- **ロール**: MEMBER / APPROVER 共通（自分の予約のみ閲覧。本機能はロールによる絞り込み挙動の差がないため統合）
- **特徴**: `/reservations` 画面で自分が行った予約を確認・管理している
- **動機**: 予約件数が増えると、ステータスタブだけでは目的の予約（特定のリソース・特定の期間）を見つけにくくなる。どのリソースを予約したか、いつの予約かで絞り込みたい
- **利用シーン**: 「来週の会議室の予約だけ見たい」「プロジェクターの予約履歴を確認したい」といった場面でリソース名・期間フィルタを操作する

## ペルソナ 2: ADMIN（補助ペルソナ）

- **ロール**: ADMIN
- **特徴**: 主ペルソナの操作に加えて、全ユーザーの予約を一覧で閲覧できる（既存仕様）
- **動機**: フィルタ機能を使っても、既存の「ADMIN は全予約を閲覧できる」可視範囲が変わらないことを期待する
- **利用シーン**: 全ユーザーの予約を対象に、リソース名・期間で絞り込んで管理業務を行う

## ペルソナ・ストーリー マッピング

| ストーリー | 主ペルソナ | ADMIN 補助ペルソナ |
|---|---|---|
| US-01 リソース名で予約を絞り込む | ✅ | ✅（全予約対象でも同様） |
| US-02 期間で予約を絞り込む | ✅ | ✅ |
| US-03 ステータス・リソース名・期間を組み合わせて絞り込む | ✅ | ✅ |
| US-04 フィルタをリセットして全件表示に戻す | ✅ | ✅ |
