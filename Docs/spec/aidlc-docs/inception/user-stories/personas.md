# Personas: CSV 帳票出力

## 管理者（ADMIN）

- **役割**: BookFlow の管理者ロール。リソース管理・ユーザー管理を日常的に行う
- **ゴール**: 予約実績を社内報告や Excel での集計に使えるようにしたい
- **現状の課題**: 予約データは画面上でしか閲覧できず、Excel への転記や社内報告に手作業でコピーする必要がある
- **技術的な習熟度**: BookFlow の管理者ページ（リソース管理・ユーザー管理）の操作には慣れているが、API を直接叩くようなことはしない。Excel での集計作業を日常的に行う

> 本機能は ADMIN ロールのみがアクセスできる。MEMBER・APPROVER は「アクセスを拒否される側」として登場するが、独立したペルソナは立てない（既存の `/admin/resources` 等と同じロール境界であり、新たな人物像を必要としないため）。
