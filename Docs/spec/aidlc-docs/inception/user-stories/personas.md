# Personas

> Minimal 深さでの生成（`../plans/user-stories-assessment.md` 参照）。本タスクはロール間の挙動差分がないため、単一ペルソナとする。

## 会員（検索する利用者）

- **役割**: `MEMBER` / `APPROVER` / `ADMIN` いずれのロールも、リソース一覧でリソースを検索する際はこのペルソナとして振る舞う（検索機能自体に権限差はない。ADMIN 固有の `is_active=false` 可視性は既存仕様のまま変わらない）
- **ゴール**: 増え続けるリソースの中から、名称や説明文のキーワードで目的のリソースを素早く見つけたい
- **現状の課題**: カテゴリと期間でしか絞り込めず、名称・説明文に手がかりがあっても検索できない
- **利用文脈**: `/resources` 画面で、カテゴリ・期間フィルタと組み合わせて使うことが多い
