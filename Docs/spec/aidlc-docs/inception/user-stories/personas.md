# Personas — csv-report

## ペルソナ1：ADMIN（管理者）

- **役割**: 全予約・全リソースを管理する
- **特性**: 予約データを Excel などに転記し、社内報告や利用状況の把握に使う。期間やステータスを絞って出力したい場面が多い
- **動機**: 画面で見ている予約一覧を、そのままの条件でファイルとして持ち出したい。Excel で開いたときに文字化けや数式の誤動作が起きない CSV が欲しい

## ペルソナ2：MEMBER（一般社員）

- **役割**: 会議室・設備の予約を申請する
- **特性**: 自分の予約だけを閲覧できる立場。他人の予約を含む帳票を取得する権限はない
- **動機**: 帳票出力の機能があっても、自分の権限で他人の予約情報が持ち出されることはないと期待する（ボタンは表示されず、API を直接呼んでも 403）

## ペルソナ3：APPROVER（承認者）

- **役割**: 要承認リソースの予約申請を承認・却下する
- **特性**: 承認業務のために予約の一部を閲覧できるが、全予約の帳票出力は ADMIN の権限に限られる
- **動機**: MEMBER と同様に、承認者の権限では CSV を取得できないことが、予約情報の取り扱いルールとして一貫していてほしい
