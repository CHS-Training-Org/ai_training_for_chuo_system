# Personas: CSV 帳票出力（Issue #29）

ロールの定義は `docs-next/docs/spec/requirements.md`（MEMBER / APPROVER / ADMIN）に従う。業務上の目的はビジネス要求シートの背景（Excel 等への転記、社内報告への利用）から取る。個人名や経歴などの架空の属性は付けない。

## P1 管理者（ADMIN）：主ペルソナ

- **ロールと権限**: リソース管理、ユーザー一覧の参照、全ユーザーの予約一覧の参照ができる。`/admin/*` 配下の画面に入れる
- **目的**: 予約データを Excel 等に取り込み、社内報告や集計に使う。現状は画面で閲覧するしかなく、転記に手間がかかる
- **本機能との関係**: CSV 帳票出力を使う唯一のロール。予約一覧画面（`/reservations`）で、期間とステータスを指定して CSV をダウンロードする
- **期待すること**: Excel で開いたときに文字化けせず、画面と同じ言葉（状態の表示名など）で読めること。必要な範囲だけを取り出せること

## P2 一般社員（MEMBER）：使えないことを確認する対象

- **ロールと権限**: リソース検索、予約申請、自分の予約の参照・更新・キャンセルができる
- **本機能との関係**: CSV 帳票出力を使えない。予約一覧画面に CSV ダウンロードの UI は表示されず、API を直接呼んでも 403 になる
- **確認する理由**: 全ユーザーの予約（他人の申請者名や利用目的を含む）を持ち出せないようにするため

## P3 承認者（APPROVER）：使えないことを確認する対象

- **ロールと権限**: MEMBER の権限に加え、承認待ち一覧の参照と承認・却下ができる。他人の予約の詳細も参照できる
- **本機能との関係**: CSV 帳票出力を使えない。表示と API の扱いは MEMBER と同じ
- **確認する理由**: 他人の予約を参照できる権限があっても、帳票の出力は ADMIN に限るという要件（RPT-04）を、MEMBER とは別に確かめる必要があるため
