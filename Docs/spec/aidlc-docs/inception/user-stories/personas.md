# Personas — リソース一覧の検索・フィルタ追加

## ペルソナ 1: BookFlow 認証済みユーザー（主ペルソナ）

- **ロール**: MEMBER / APPROVER / ADMIN 共通（本機能はロールによる検索挙動の差がないため統合）
- **特徴**: 会議室・備品・車両の予約のために `/resources` 画面でリソースを探している
- **動機**: リソース数が増えるほど、カテゴリ・期間フィルタだけでは目的のリソースを見つけにくくなる。名称や説明文の一部が分かっていれば、それを手がかりに絞り込みたい
- **利用シーン**: 「プロジェクター」「会議室」のような単語で検索し、該当するリソースだけを一覧で確認する

## ペルソナ 2: ADMIN（補助ペルソナ）

- **ロール**: ADMIN
- **特徴**: 主ペルソナの操作に加えて、無効化済み（`is_active = false`）のリソースも一覧に含めて閲覧できる（既存仕様）
- **動機**: 無効化済みリソースも含めてキーワードで検索し、再有効化や管理の要否を確認したい
- **利用シーン**: keyword 検索を使っても、既存の「ADMIN は inactive も含む」挙動がそのまま維持されることを期待する

## ペルソナ・ストーリー マッピング

| ストーリー | 主ペルソナ | ADMIN 補助ペルソナ |
|---|---|---|
| US-01 キーワードでリソースを絞り込む | ✅ | ✅（inactive 含む結果に対しても同様） |
| US-02 キーワードを解除して全件に戻す | ✅ | ✅ |
| US-03 カテゴリ・期間とキーワードを組み合わせる | ✅ | ✅ |
| US-04 検索結果が 0 件のときに分かりやすい表示を見る | ✅ | ✅ |
