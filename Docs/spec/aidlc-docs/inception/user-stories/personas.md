# Personas — リソース一覧のソート順選択

## ペルソナ 1: BookFlow 認証済みユーザー（主ペルソナ）

- **ロール**: MEMBER / APPROVER / ADMIN 共通（本機能はロールによるソート挙動の差がないため統合）
- **特徴**: 会議室・備品・車両の予約のために `/resources` 画面でリソースを探している
- **動機**: リソース件数が多いとき、登録日時順（現状の固定表示）では目的のリソースを探しにくい。名前のあいうえお順（アルファベット順）や、定員の大きい順で一覧を並べ替えて探したい
- **利用シーン**: 「会議室を定員の大きい順に見たい」「備品を名前順に見たい」といった場面でソート選択ドロップダウンを操作する

## ペルソナ 2: ADMIN（補助ペルソナ）

- **ロール**: ADMIN
- **特徴**: 主ペルソナの操作に加えて、無効化済み（`is_active = false`）のリソースも一覧に含めて閲覧できる（既存仕様）
- **動機**: ソート機能を使っても、既存の「ADMIN は inactive も含む」可視範囲が変わらないことを期待する
- **利用シーン**: inactive リソースを含む一覧を、名称順や定員順で並べ替えて確認する

## ペルソナ・ストーリー マッピング

| ストーリー | 主ペルソナ | ADMIN 補助ペルソナ |
|---|---|---|
| US-01 名称順でリソースを並べ替える | ✅ | ✅（inactive 含む結果に対しても同様） |
| US-02 定員順でリソースを並べ替える | ✅ | ✅ |
| US-03 ソート未選択時は登録日時順で表示される | ✅ | ✅ |
| US-04 カテゴリ・期間・キーワードフィルタと組み合わせてソートする | ✅ | ✅ |
