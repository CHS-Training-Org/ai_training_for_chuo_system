# Personas — calendar-view

## 主ペルソナ：BookFlow 認証済みユーザー

- **役割**: MEMBER・APPROVER・ADMIN いずれかのロールでサインイン済みの社員
- **特性**: 会議室・設備の予約を日常的に行う。リソース詳細画面で空き状況を確認したうえで予約申請する
- **動機**: 「このリソースはいつ空いているか」を週・月単位で一目で把握し、空いている時間帯をすぐに予約したい
- **本課題との関係**: カレンダービューの表示・操作（週/月切り替え、期間移動、空き枠クリック）はロールに関わらず同一の挙動を持つ（requirements.md のとおり権限による表示差分はない）ため、本課題では単一ペルソナとして扱う
