# Personas — resource-detail-info

## ADMIN（リソース管理者）

- **役割**: 施設・備品・車両の登録・編集・有効/無効切替を行う運用担当者。
- **特性**: `/admin/resources` 画面から `ResourceManagementClient` のフォームを操作する。既存7フィールド（名前・カテゴリ・定員・場所・承認フロー要否・有効フラグ・説明）の入力に慣れている。
- **動機**: 予約前に利用者が確認すべき設備情報・注意事項を漏れなく登録し、問い合わせや予約後のトラブルを減らしたい。

## MEMBER / APPROVER（一般利用者・承認者）

- **役割**: リソースを予約する一般利用者（MEMBER）、または予約の承認可否を判断する承認者（APPROVER）。
- **特性**: `/resources/{id}` のリソース詳細画面を閲覧する点で両者の挙動は同一（本課題において閲覧ロールを区別する要件はない）。
- **動機**: 予約前に設備（プロジェクターの有無等）や利用上の注意（騒音制限・清掃ルール等）を確認し、目的に合ったリソースかを判断したい。
