# Integration Test Instructions（csv-export）

自動の結合テストは追加していない（BE は `ReportControllerTest` が MockMvc で Controller から Writer まで通す）。FE から BE を通した確認は、下記の手動確認で行う。

## Setup
```bash
docker compose -f .devcontainer/docker-compose.yml up -d
cd backend && ./gradlew bootRun
cd frontend && pnpm dev
```
サインインは開発専用のロール別ログインボタンを使う（ブラウザの OAuth サインインはローカルでは動かない）。

### テストデータ（開発 DB のみ。Flyway には入れない）
`reservations` に id `90000000-0000-0000-0000-00000000000{1..6}` の 6 件を入れる。

| 末尾 | 開始日時 | status | purpose | 狙い |
|---|---|---|---|---|
| 1 | 2026-09-30 23:30 | APPROVED | 境界A 9月末（期間外） | 期間の下側の外 |
| 2 | 2026-10-01 00:00 | APPROVED | 境界B 10月1日0時（含む） | 開始日当日 0 時 |
| 3 | 2026-10-31 23:30 | REJECTED | 境界C 10月31日末（含む） | 終了日当日の末尾 |
| 4 | 2026-11-01 00:00 | CANCELLED | 境界D 11月1日0時（除く） | 期間の上側の外 |
| 5 | 2026-10-15 09:00 | APPROVED | `=1+1` | 数式インジェクション対策 |
| 6 | 2026-10-16 09:00 | APPROVED | `資料,"確認"` + 改行 + `2行目` | CSV エスケープ |

`resource_id` は `30000000-0000-0000-0000-00000000000{2,3}`、`requester_id` は `20000000-0000-0000-0000-000000000001`（既存のシード）。

後始末: `DELETE FROM reservations WHERE id::text LIKE '90000000%';`

## 確認観点（15 項目）
| # | 観点 | 操作 | 期待結果 |
|---|---|---|---|
| 1 | 権限（画面） | MEMBER と APPROVER でサイドナビを見る。`/admin/reservations` を直接開く | 「予約帳票」は出ない。直接開くと 403 画面 |
| 2 | 権限（API） | MEMBER で `http://localhost:3000/api/reports/reservations/csv` を開く。サインアウト後にも開く | MEMBER は `{"code":"FORBIDDEN",...}`、未ログインは 401 の JSON。ファイルは落ちない |
| 3 | 表示 | ADMIN でサイドナビの「予約帳票」を開く | 開始日、終了日、ステータス 4 種（承認待ち、承認済み、却下、キャンセル済み）、ボタン |
| 4 | 条件なし | 何も入れずに押す | `reservations_<出力日>.csv`。全件が開始日時の昇順 |
| 5 | Excel | 保存したファイルを Excel で開く | 文字化けしない。日時は `2026-10-02 10:00` 形式 |
| 6 | 数式対策 | `=1+1` の行 | セルは `'=1+1` の文字列で計算されない |
| 7 | エスケープ | 「資料,"確認"」の行 | カンマ、引用符、改行を含めて 1 セルに入る |
| 8 | 期間の境界 | 開始日 2026-10-01、終了日 2026-10-31 | ファイル名 `reservations_20261001_20261031.csv`。境界B、境界C、`=1+1`、「資料」は入り、境界A、境界D は入らない |
| 9 | 片方だけ | 開始日のみ、終了日のみ | どちらも成功。ファイル名は出力日 |
| 10 | ステータス | 「承認済み」のみ、「承認待ち」+「却下」 | 指定したステータスの行だけ。複数は OR |
| 11 | 期間 + ステータス | 10 月、「承認済み」 | 境界B、`=1+1`、「資料」だけ（AND） |
| 12 | 0 件 | 2030-01-01 から 2030-01-31 | ヘッダ行だけの CSV。エラーにならない |
| 13 | 入力検証 | 開始日 2026-10-31、終了日 2026-10-01 | 「開始日は終了日以前の日付にしてください。」のトースト。Network に reports へのリクエストが出ない |
| 14 | サーバー側エラー | `dev-id-token` cookie を削除して押す | 認証エラーのトースト。ダウンロードされない |
| 15 | 回帰 | `/reservations`、リソース一覧、承認待ち一覧 | 従来どおり動く |

## 結果
2026-10-29、学習者が上記 15 項目を実施し、すべて問題なしと報告（操作は学習者、テストデータ投入は AI が実施）。

## 対象外
- Playwright の E2E（`e2e-test-coverage` 課題の範囲）、性能テスト、セキュリティテスト（拡張ルールは No）
- 件数上限なし（メモリ上で組み立てる）は設計 Q3 で決めた既知の制約。大量データでの性能は未検証。
