# Business Rules — calendar-view

| # | ルール |
|---|--------|
| BR-01 | カレンダーの表示モードは「週表示」「月表示」の2種類のみ。日表示・年表示は対象外 |
| BR-02 | 週表示の週は月曜始まり（月〜日の7日間） |
| BR-03 | 週表示の時間軸は8:00〜20:00の1時間刻みグリッド（12セル×7日）。この範囲外の時間帯は表示しない |
| BR-04 | セルの占有判定は半開区間 `[start, end)` の重なりで行う。隣接する区間（例：10:00〜11:00の予約と11:00〜12:00のセル）は重ならない扱いとする（既存バックエンドの重複判定ロジックと同じ方針） |
| BR-05 | 月表示の日セルは、営業時間（8:00〜20:00）が占有スロットで完全に埋まっている場合のみ「予約済み」としてグレーアウト・クリック不可にする。一部でも空いていればクリック可能とする |
| BR-06 | 月表示でクリック可能な日セルをクリックした場合、実際にその日のどの時間帯が空いているかの最終確認は行わない。予約申請フォーム提出時の既存の重複チェック（バックエンド）に委ねる |
| BR-07 | 表示期間（週・月）を移動するたびに、`GET /api/resources/{id}/availability` を新しい期間のfrom/toで再呼び出しする。古い期間のデータを使い回さない |
| BR-08 | `isActive=false` のリソースでは、カレンダー自体は表示するが空き枠のクリック（予約申請フォームへの遷移）は無効にする。画面上部の「このリソースを予約する」ボタンが`isActive=false`時に非表示になる既存の挙動と一貫させ、無効なリソースへの新規予約導線を作らない |
