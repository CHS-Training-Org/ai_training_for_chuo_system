# 運営ノートの同期

運営ノート（`ops-note/index.html`、Pages の `/ops-note/` で公開）は、受講者向けの運営情報の置き場である。手順の真実の源はドキュメントサイトだが、運営ノートにはカリキュラムやルールの一部が写しとして載っている。写し元を変えたのに運営ノートを直さないと、受講者が食い違った案内を見る。運営ノートは素の HTML で、ドキュメントサイトのビルドのリンク切れのチェックも効かない。

## 適用対象

次のいずれかを変えるときは、**同じ変更の中で** `ops-note/index.html` の該当する節を見直し、食い違えば直す。

- `docs-next/docs/learn/curriculum.md`：STEP の構成、必須と任意、完了条件の所在（運営ノートの「進め方」）
- `docs-next/docs/develop/dev-workflow.md`：PR の宛先、マージの扱い（運営ノートの「各タスクの補足」）
- `docs-next/docs/operations/operations-guide.md`：質問の窓口、対応方針（運営ノートの「質問・サポート」）
- 運営ノートの「ドキュメントサイト内の主要な行き先」にあるページの移動、名前の変更、削除
- ドキュメントサイトの公開 URL の変更

見直した結果、直す必要がなければ、運営ノートは変えなくてよい。

## 見直しの仕方

- 運営ノートのどの節が何の写しかは、[運用ガイドの「運営ノートの保守」](../../docs-next/docs/operations/operations-guide.md#ops-note)の表にある。
- スタイルは `ops-note/style.css` にあり、色と書体はリポジトリ直下の `DESIGN.md` に従う。
- 見た目は、ファイルをブラウザで開いて確かめる。リンクは手で確かめる。

## 位置づけ

`agent-config-sync.md` と同じく、強制力はなく、常時ロードされる文脈として見直しを促すものである。スケジュール、録画、事前準備など、ドキュメントサイトの外が情報源の節は、このルールでは拾えない。それらは運用ガイドの手順に従って運営者が更新する。
